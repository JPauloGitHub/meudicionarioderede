Modelo OSI

  1. Física ::
    • (Physical Layer) Transforma os dados em bits(zero e um) e gerencia o envio desses sinais físicos pelo meio(seja por impulsos elétricos em cabos de cobre, luz em fibras ópticas ou ondas de rádio no Wi-Fi).
  2. Enlace ::
    • (Data Link Layer) organiza os bits vindos da camada física em pacotes chamados quadros(frames), adiciona os endereços MAC de origem e destino, e faz o controle de erros básicos na rede local.
  3. Rede ::
    • (Network Layer) determina o melhor caminho para os dados viajarem de uma rede para outra(roteamento), utilizando endereços lógicos(como os endereços IP). É aqui que entram os pacotes de dados.
  4. Transporte ::
    • (Transport Layer) divide os dados das aplicações em pedaçoes menores(segmentos), controla o fluxo de entrega e verifica se houve perda de pacotes, retransmitindo se necessário.
  5. Sessão ::
    • (Session Layer) Estabelece, mantém, sincroniza e encerra a sessão de comunicação entre as aplicações, garantindo que o diálogo continue de onde parou caso ocorra uma queda temporária.
  6. Apresentação ::
    • (Presentation Layer) Garante que os dados enviados por um sistema possam ser compreendidos pelo outro, cuidando da conversão de formatos, compressão de dados e criptografia/descriptografia(como o SSL/TLS).
  7. Aplicação ::
    • (Application Layer) Fornece a interface direta para que os programas do usuário interajam com a rede, oferecendo os serviços de comunicação que usamos no dia a dia.
