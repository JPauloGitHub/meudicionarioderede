Conceitos

  1. IP ::
    • (Internet Protocol) é um conjunto de regras que permite a comunicação entre dispositivos em uma rede, como a internet. Ele identifica cada dispositivo conectado por meio de um endereço IP, funciona de uma forma semelhante ao endereço de uma residencia para envio e recebimento de de dados.
  2. DNS ::
    • (Domain Name System) é o sistema que traduz nomes em endereço IP
  3. DHCP ::
    • (Dynamic Host Configuration Protocol) é o protocolo que distribui automaticamente endereços IP e outras configurações de rede aos dispositivos conectados em uma rede.
  4. MAC ::
    • (Media Access Control) é um endereço físico único atribuído à placa de rede de um dispositivo. Ele identifica o equipamento dentro de uma rede local.
  5. LAN ::
    • (Local Area Network) é uma rede local que conecta dispositivos em uma área limitada, como uma casa, escola ou empresa. Ela permite o compartilhamento de recursos e a comunicação entre dispositivos conectados.
  6. WAN ::
    • (Wide Area Network) é uma rede de longa distância que conecta diferentes redes locais (LANs) em grande áreas geográficas. A internet é o maior exemplo de WAN.
  7. SSID ::
    • (Service Set Identifier) é o nome de uma Wi-Fi. Ele identifica a rede sem fio para que dispositivos possam encontrá-la e se conectar a ela.
