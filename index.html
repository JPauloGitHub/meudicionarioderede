Conceitos

  1. IP ::
    • (Internet Protocol) é um conjunto de regras que permite a comunicação entre dispositivos em uma rede, como a internet. Ele identifica cada dispositivo conectado por meio de um endereço IP, funciona de uma forma semelhante ao endereço de uma residencia para envio e recebimento de de dados.
  2. DNS ::
    • (Domain Name System) é o sistema que traduz nomes em endereço IP
  3. DHCP ::
    • (Dynamic Host Configuration Protocol) é o protocolo que distribui automaticamente endereços IP e outras configurações de rede aos dispositivos conectados em uma rede.
  4. MAC ::
    • (Media Access Control) é um endereço físico único atribuído à placa de rede de um dispositivo. Ele identifica o equipamento dentro de uma rede local.
  5. LAN ::
    • (Local Area Network) é uma rede local que conecta dispositivos em uma área limitada, como uma casa, escola ou empresa. Ela permite o compartilhamento de recursos e a comunicação entre dispositivos conectados.
  6. WAN ::
    • (Wide Area Network) é uma rede de longa distância que conecta diferentes redes locais (LANs) em grande áreas geográficas. A internet é o maior exemplo de WAN.
  7. SSID ::
    • (Service Set Identifier) é o nome de uma Wi-Fi. Ele identifica a rede sem fio para que dispositivos possam encontrá-la e se conectar a ela.
  8. TCP ::
    • (Transmission Control Protocol) é um protocolo de comunicação que garante a entrega correta e completa dos dados entre dispositivos em uma rede. Ele verifica erros e reorganiza os pacotes para que as informações cheguem de forma confiável ao destino.
  9. UDP ::
    • (User Datagram Protocol) é um protocolo de comunicação que envia dados rapidamente, sem verificar se eles chegaram corretamente ao destino. É mais rápido que o TCP, mas menos confiável, pois ignora as perdas de pacotes, priorizando a entrega.
  10. HTTP ::
    • (Hypertext Transfer Protocol) é o protocolo base da Web. Ele funciona como uma "lingua comum" para a torca de informações na internet.
  11. HTTPS ::
    • (Hypertext Transfer Protocol Secure) é a evolução segura do HTTP. Ele funciona exatamente da mesma forma para a troca de dados, mais adiciona uma camada de criptografia (geralmente usando os protocolos TLS ou SSL) entre o seu navegador e o servidor.
  12. FTP ::
    • (File Transfer Protocol ou Protocolo de Transferência de Arquivos) é um protocolo clássico da internet usado exclusivamente para enviar e baixar arquivos entre um computador local e um seridor remoto.
  13. SMTP ::
    • (Simple Mail Transfer Protocol) é o protocolo padrão da internet usado exclusivamente para enviar e-mails.
  14. PoP3 ::
    • (Post Office Protocol version 3) é o protocolo padrão de email usado especificamente para baixar as mensagens de um servidor de correio para o seu dispositivo local (como um computador ou aplicativo de celular).
  15. IMAP ::
    • (Internet Message Access Protocol) é o protocolo padrão da internet para acessar e sincronizar e-mails diretamente no servidor.
  16. NAT ::
    • (Network Address Translation ou Tradução de Endereço de Rede) é o sistema que traduz os endereços IP da sua rede interna (como os vários aparelhos da sua casa) para um único endereço IP público, permitindo que todos naveguem na internet ao mesmo tempo usando a mesma conexão.
  17. VPN ::
    • (Virtual Private Network ou Rede Privada Virtual) é uma tecnologia que cria uma conexão criptografada e segura entre o seu dispositivo (computador, celular) e a internet, funcionando como um "tunnel" privado.
  18. ARP ::
    • (Address Resolution Protocol ou Protocolo de Resolução de Endereço) é o protocolo responsável por conectar o endereço IP(lógico) ao endereço MAC(físico) da placa de rede de um dispositivo.
  19. ICMP ::
    • (Internet Control Message Protocol) é um protocolo da camada de rede usado principalmente para diagnósticos, ralatórios de erros e testes de conectividade.
  20. TTL ::
    • (Time to Live ou Tempo de Vida) é um mecanismo de controle usado na internet com dois significados principais: em pacotes de rede (IP) e no DNS.
  21. MTU ::
    • (Maximum Transmission ou Unidade Máxima de Transmissão) é o tamanho máximo de um pacote de dados(em bytes) que pode ser transmitido de uma só vez por uma rede sem precisar ser fragmentado.
  22. VLAN ::
    • (Virtual Local Area Network ou Rede Local Virtual) é uma técnica usada em redes de computadores para dividir uma rede física única em várias redes virtuais independentes.
  23. PoE ::
    • (Power over Ethernet ou Energia sobre Ethernet) é uma tecnologia que permite transmitir energia elétrica e dados de rede pelo mesmo cabo de rede (cabo Ethernet/RJ-45).
